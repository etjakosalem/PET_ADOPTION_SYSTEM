# PET_ADOPTION_SYSTEM

The ACPaws Pet Adoption Management System is a web-based platform designed to help ACPaws Shelter efficiently manage pet adoption operations. It allows administrators to maintain pet records, manage staff information, review adoption requests, and log completed adoptions. Visitors can browse available pets and submit adoption requests online. The system improves organization, reduces manual paperwork, and provides a streamlined process for both shelter staff and adopters.

System Flow
User enters system
Selects Admin or Visitor
Visitor: Browses pets → Submits adoption request
Admin: Logs in → Reviews requests
Admin approves/rejects request
If approved → Assign staff & record adoption
Pet status updated to adopted
Records saved in database/local storage
